## Exemplo de classe em Javascript

```javascript
class Ponto {
    constructor(x, y) {
        this.x = x;
        this.y = y;
    }
    
    distancia(outroPonto) {
        const dx = this.x - outroPonto.x;
        const dy = this.y - outroPonto.y;
        return Math.sqrt(dx * dx + dy * dy);
    }
}
```

Usando:

```javascript
let p1 = new Ponto(10, 10);
let p2 = new Ponto(0, 0);

console.log(p1.distancia(p2));
```

## Composição

Composição é um mecanismo da orientação a objetos que permite que uma classe seja composta por outras classes, ou seja,
uma classe pode ter instâncias de outras classes como propriedades. Isso promove o reuso de código e a modularidade.

```javascript
class Triangulo {
    constructor(p1, p2, p3) {
        this.p1 = p1;
        this.p2 = p2;
        this.p3 = p3;
    }

    perimetro() {
        return this.p1.distancia(this.p2) + this.p2.distancia(this.p3) + this.p3.distancia(this.p1);
    }
    
    area() {
        const a = this.p1.distancia(this.p2);
        const b = this.p2.distancia(this.p3);
        const c = this.p3.distancia(this.p1);
        const s = (a + b + c) / 2;
        return Math.sqrt(s * (s - a) * (s - b) * (s - c));
    }
}
```

## Herança

Herança é um mecanismo da orientação a objetos que permite que uma classe herde propriedades e métodos de outra classe.
Em Javascript, isso é feito usando a palavra-chave `extends`.

```javascript
class Ponto3D extends Ponto {
    constructor(x, y, z) {
        super(x, y);
        this.z = z;
    }

    distancia(outroPonto) {
        const dx = this.x - outroPonto.x;
        const dy = this.y - outroPonto.y;
        const dz = this.z - outroPonto.z;
        return Math.sqrt(dx * dx + dy * dy + dz * dz);
    }
}
```
