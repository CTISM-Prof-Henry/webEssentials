# Componentes

Em desenvolvimento Web, componentes são pedaços de código HTML, CSS e Javascript que funcionam juntos, e desempenham
funções pré-definidas.

Componentes podem ser botões, entradas de texto de formulários, dropdowns, modais, etc. 

Existem bibliotecas de componentes prontas, como o [Bootstrap](https://getbootstrap.com/).
Todavia, neste documento, o objetivo é criar componentes do zero, para entender como eles funcionam.
