# Formulários

Formulários são uma parte essencial de muitas páginas Web, permitindo que os usuários insiram dados e interajam com o
site. Eles são criados usando a tag `<form>` e podem conter diversos tipos de campos de entrada, como texto, senha,
email, número, entre outros. Além disso, os formulários podem ser estilizados com CSS e manipulados com Javascript para
criar experiências de usuário mais ricas e interativas.

> [!NOTE]
> Consulte a documentação no W3Schools para uma lista completa e interativa de tipos de campos de
> entrada: https://www.w3schools.com/html/html_form_input_types.asp

## Exercícios

1. Crie um formulário simples com um campo de texto para o nome do usuário e um botão de envio. Ao enviar o formulário,
   o site deve exibir uma mensagem de boas-vindas com o nome do usuário.
2. Crie um formulário com um campo de email e um botão de envio. Valide o campo de email usando Javascript para garantir
   que o usuário insira um endereço de email válido antes de permitir o envio do formulário.
3. Crie um formulário com um campo de senha e um botão de envio. Adicione um recurso de "mostrar senha" usando
   Javascript, permitindo que o usuário veja o texto da senha enquanto a digita.
4. Crie um formulário com um campo de texto e um botão de envio. O usuário deve entrar um CPF no campo de texto. Realize
   validação do número do CPF usando Javascript. Você pode consultar como é feita a validação 
   [aqui](https://dicasdeprogramacao.com.br/algoritmo-para-validar-cpf/).
5. Crie um formulário com um campo de seleção (dropdown) e um botão de envio. O campo de seleção deve conter opções para
   escolher a cor de fundo da página. Ao enviar o formulário, a cor de fundo da página deve mudar para a cor selecionada
   pelo usuário.
