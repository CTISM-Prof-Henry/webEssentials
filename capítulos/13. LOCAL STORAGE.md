# Local Storage

Local storage é uma das duas maneiras (a outra sendo indexedDB) de armazenar dados no navegador. Ele é projetado para
armazenar dados simples, como strings, e tem uma capacidade de armazenamento de cerca de 5MB por domínio. Local storage
é acessível através do objeto `localStorage` em JavaScript.

Podemos usar local storage para, por exemplo, salvar dados de preferência do usuário, como o tema do site (claro ou
escuro), ou para armazenar dados temporários que não precisam ser enviados para um servidor.

## Armazenando dados

Para armazenar dados no local storage, você pode usar o método `setItem`:

```javascript
localStorage.setItem('chave', 'valor');
```

## Recuperando dados

Para recuperar dados do local storage, você pode usar o método `getItem`:

```javascript
const valor = localStorage.getItem('chave');
console.log(valor); // Output: 'valor'
```

## Removendo dados

Para remover um item específico do local storage, você pode usar o método `removeItem`:

```javascript
localStorage.removeItem('chave');
```
