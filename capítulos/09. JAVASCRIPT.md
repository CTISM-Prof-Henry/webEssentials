## Introdução

Javascript é uma linguagem de programação interpretada, fracamente tipada, geralmente executada nos navegadores Web 
(como será visto nesta disciplina), ou então em frameworks backend que usam Javascript como linguagem, como 
[node.js](https://nodejs.org/pt-br).

A linguagem Javascript é muito semelhante a linguagem de programação C, à exceção da tipagem fraca. 

<img src="https://asset-cdn.tecky.io/2021/10/20/programming_languages_family_trees_uid_616fd206b9de0.png" width=500px>

Um código-fonte em C que soma dois números e imprime na tela é

```C
#include <stdio.h>

int main() {
    int a = 2;
    int b = 3;
    int soma = a + b;
    printf("A soma é: %d\n", soma);
    return 0;
}
```

O equivalente em Javascript é 

```javascript
let a = 2;
let b = 3;
let soma = a + b;
console.log("A soma é: " + soma);
```

> [!NOTE]
> **Diferença entre `let` e `var`**
> Consulte o site [Design Gurus](https://www.designgurus.io/answers/detail/what-is-the-difference-between-let-and-var)
> para uma explicação detalhada sobre a diferença entre `let` e `var`.

## Operadores matemáticos

Os operadores matemáticos são os mesmos da linguagem C: `+`, `-`, `*`, `/`, `%`, mais o operador `**`, que faz 
potenciação:

```javascript
let a = 2;
let b = 3;
let soma = a + b; // 5
let subtracao = a - b; // -1
let multiplicacao = a * b; // 6
let divisao = a / b; // 0.6666...
let resto = a % b; // 2
let potencia = a ** b; // 8
```

## Operadores lógicos

Além dos operadores matemáticos, Javascript possui os seguintes operadores lógicos: `&&` (AND), `||` (OR) e `!` (NOT):

```javascript
let a = true;
let b = false;
console.log(a && b); // false
console.log(a || b); // true
console.log(!a); // false
console.log(!b); // true
```

## Desvio condicional

O desvio condicional é feito usando os operadores `if`, `else if` e `else`:

```javascript
let temperatura = 25;
if (temperatura < 10) {
    console.log("Está frio!");
} else if ((temperatura >= 10) && (temperatura <= 20)) {
    console.log("Está ameno!");
} else {
    console.log("Está quente!");
}
```

## Laços de repetição

Os laços de repetição mais comuns em Javascript são `for`, `while` e `do-while`:

```javascript
// Laço for
for (let i = 0; i < 5; i++) {
    console.log(i);
}
```

```javascript
// Laço while
let i = 0;
while (i < 5) {
    console.log(i);
    i++;
}
```

```javascript
// Laço do-while
let i = 0;
do {
    console.log(i);
    i++;
} while (i < 5);
```

## Arrays

Arrays são estruturas de dados que armazenam uma coleção de elementos. Em Javascript, os arrays são dinâmicos e podem conter
elementos de diferentes tipos:

```javascript
let array = [1, "dois", 3.14, true];
console.log(array[0]); // 1
console.log(array[1]); // "dois"
console.log(array[2]); // 3.14
console.log(array[3]); // true
```

Você pode iniciar um array vazio e inserir itens à ele iterativamente:

```javascript
let array = [];
array.push(1);
array.push("dois"); 
array.push(3.14);
array.push(true);
console.log(array);
```

Ou então, iniciar com um array cheio e remover itens iterativamente:

```javascript
let array = [1, "dois", 3.14, true];
array.pop(); // remove o último item (true)
array.shift(); // remove o primeiro item (1)
```

Para ver o tamanho de um array, use o atributo `length`:

```javascript
let array = [0, 1, 2, 3, 4];
console.log(array.length); // 5
```

## Strings

Strings são arrays de caracteres. Além de todas as operações sobre array se aplicarem à strings, elas possuem métodos
específicos para manipulação de texto:

```javascript
let frase = "Olá Mundo!";
console.log(frase.length); // 10
console.log(frase.toUpperCase()); // "OLÁ MUNDO!"
console.log(frase.toLowerCase()); // "olá mundo!"
console.log(frase.includes("Mundo")); // true
console.log(frase.replace("Mundo", "JS")); // "Olá JS!"
``` 

## Funções

Diferentemente de C, funções em Javascript não precisam de um tipo de retorno definido, e podem ser anônimas (sem nome). 
Elas também podem ser armazenadas em variáveis, passadas como parâmetros para outras funções, e retornadas por outras 
funções.

```javascript
// Função nomeada
function soma(a, b) {
    return a + b;
}   

// Função anônima armazenada em uma variável
let multiplicacao = function(a, b) {
    return a * b;
};  
```
