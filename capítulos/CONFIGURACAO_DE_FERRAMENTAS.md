# Configuração de Ferramentas

>[!IMPORTANT]
> O tutorial desta página pode já estar defasado. Ou seja, as ferramentas podem ter mudado o local das configurações. Se
> for esse o caso, pesquise na internet por instruções mais atualizadas!

Esta página descreve as ferramentas necessárias para acompanhar a disciplina.

## Navegador Web

* **💡 Importância:** muito importante
* **🧑‍🍳 Recomendação:** [Firefox](https://www.firefox.com/pt-BR/)
* **🗺️ Alternativas:** Qualquer outro

Sem um navegador, é impossível visualizar o resultado do código-fonte. Qualquer navegador moderno será suficiente, desde
que mantido atualizado (e geralmente eles se atualizam sozinhos, não sendo preciso fazer nada).

A recomendação é usar um navegador que seja compatível com a maioria das tecnologias Web disponíveis, visto que nem
todas as tags e recursos CSS são compatíveis com todos os navegadores ao mesmo tempo. Você pode consultar a
compatibilidade dos recursos aqui:

* [Compatibilidade de tags HTML](https://caniuse.com/)
* [Compatibilidade de recursos CSS](https://caniuse.com/)
* [Tabelão de compatibilidade de tags HTML](https://www.w3schools.com/tags/ref_html_browsersupport.asp)
* [Tabelão de compatibilidade de recursos CSS](https://www.w3schools.com/cssref/css3_browsersupport.php)


## Editor de texto

* **💡 Importância:** opcional
* **🧑‍🍳 Recomendação:** [Sublime Text](https://www.sublimetext.com/)
* **🗺️ Alternativas:** Notepad++, bloco de notas

Caso você não queira usar um ambiente de desenvolvimento integrado (por possuir pouca memória RAM ou um processador 
mais modesto no seu computador), um editor de texto avançado como Sublime Text ou Notepad++ será suficiente. Todavia,
editores de texto não possuem recursos mais avançados (como detecção de bugs e corretores ortográficos). Será preciso
redobrar a atenção na qualidade da escrita do código-fonte.

## Ambiente de Desenvolvimento Integrado (IDE)

* **💡 Importância:** muito importante
* **🧑‍🍳 Recomendação:** [Intellij Webstorm](https://www.jetbrains.com/webstorm/)
* **🗺️ Alternativas:** Visual Code

Um Ambiente de Desenvolvimento Integrado (IDE) é como um editor de texto com esteróides. Além de um editor de texto que
possui recursos avançados, um IDE possui navegador de arquivos, detector de erros, corretor ortográfico, terminal 
integrado, etc. Esta é a opção definitiva para desenvolvimento; nenhum desenvolvedor Web sério deixa de usar uma IDE
para trabalhar.
