## Exercício 1

Crie um arquivo HTML novo para realizar as seguintes tarefas:

1. Crie um parágrafo e use CSS para alterar a cor do texto para azul.
2. Crie um título e use CSS para alterar a fonte para Arial e o tamanho para 24px.
3. Crie um link e use CSS para alterar a cor do link para verde e remover o sublinhado.
4. Crie uma imagem e use CSS para definir a largura da imagem para 200px e a altura para 150px.
5. Use CSS para alterar a borda de uma imagem de quadrada para um círculo.
6. Troque o formato de borda das imagens para um retângulo com bordas arredondadas.
7. Troque a cor de fundo da página para azul.
8. Coloque uma imagem como plano de fundo da página.
9. Crie um parágrafo e use CSS para alterar a cor do texto para vermelho quando o mouse estiver sobre ele.
10. Crie um título e use CSS para definir a posição como absoluta, posicionando-o no canto superior direito da página.
11. Crie uma div e troque a cor da borda para vermelho.
12. Crie uma tabela. Pinte o cabeçalho de outra cor.
13. Crie uma tabela. Pinte cada linha ímpar de uma cor diferente usando CSS e o seletor de pseudo-classe.

## Exercício 2

Para cada uma das tags HTML presentes na tabela, aplique as propriedades CSS dispostas nas colunas. Para cada uma das
células da tabela, descreva o comportamento apresentado.

Exemplo: Para a tag `<h1>`, utilize-a normalmente:

```html
<h1>Olá Mundo!</h1>`
```

E depois aplique o estilo disposto nas colunas:

```html
<h1 style="display: inline;">Olá Mundo!</h1>
```

Dica: Se ficar difícil de visualizar os efeitos, aplique uma cor de fundo:

```html
<h1 style="display: inline; background-color: green">Olá Mundo!</h1>
```
