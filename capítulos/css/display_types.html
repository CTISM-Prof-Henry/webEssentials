Display Types

Essa página mostra os diferentes tipos de display.

Display: block Olá Mundo! Esse tipo de display ocupa toda a largura da página.
Display: inline Olá Mundo! Esse tipo de display ocupa apenas a largura necessária ao conteúdo.
Display: inline-block Olá Mundo! Esse tipo de display permite definir um comprimento máximo do conteúdo.
Display: grid Olá Mundo! Esse tipo de display organiza os itens em uma grade.
Display: flex Olá Mundo! O display flex possui diversos controles de espaçamento, direção e sentido.
